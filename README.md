# Karbeam

차량 사진 여러 장으로 SNS 사진 게시물과 세로형 숏폼을 만드는 한국어 웹앱입니다. 프로필 온보딩 화면은 사용자가 지정한 `https://karbeam.com/onboarding/steps/profile`을 직접 확인해 한국어로 구현했습니다.

## 프로필 온보딩

처음 방문하면 이름, 성, 매매상사 이름, 직무, Karbeam을 알게 된 경로를 입력하는 프로필 화면이 표시됩니다. 이름과 성은 필수이며, 매매상사 이름·직무·유입 경로는 선택 사항입니다. 계속을 누르면 이 브라우저에만 저장한 뒤 영상 제작 화면으로 이동합니다. 나중에 하기를 누르거나 제작 화면 우측의 프로필 버튼으로 다시 편집할 수 있습니다.

## 차량 콘텐츠 제작

- 차량 사진 최대 12장 업로드, 순서 확인과 삭제
- 9:16, 4:5, 1:1, 4:3, 16:9 비율로 영상 제작
- 영상 10/25/40초, 720p/1080p, 제목·가격·자막·엔드 카드
- 본인 음성·음악 파일을 영상에 믹싱
- 차량 사진을 SNS 게시물 PNG로 생성하고 다운로드
- 영상 미리보기 및 WebM 다운로드

사진, 오디오, 프로필은 브라우저 안에서 처리합니다. 생성형 AI 영상·음성 합성·음악 생성 API는 원본 서비스가 공개한 공식 개발자 문서와 접근 자격을 확인하지 못해 연결하지 않았습니다. 앱이 원본 AI 결과라고 표시하지 않습니다. API 키를 공개 저장소나 브라우저 코드에 넣지 마세요.

## 실행 및 배포

```sh
npm ci
npm run dev
npm run build
```

`main` 브랜치에 변경이 올라오면 GitHub Actions가 GitHub Pages에 배포합니다.
