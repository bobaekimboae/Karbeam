# Karbeam

중고차 사진을 연결해 세로형 숏폼 영상을 제작하는 한국어 웹앱입니다. 화면 구성과 제작 설정은 사용자가 지정한 `iamjapinder.com/create`를 현재 기준으로 확인해 새로 구현했습니다.

## 사용 방법

1. **사진** 또는 **영상** 모드를 선택하고 차량 사진을 여러 장 추가합니다. 파일을 끌어다 놓아도 됩니다.
2. 차량명, 가격, 짧은 문구를 입력하고 스타일·길이·화면 비율·화질을 선택합니다.
3. **영상 만들기**를 눌러 브라우저에서 렌더링합니다.
4. 완성 영상 미리보기에서 재생을 확인하고 **영상 다운로드**를 누릅니다.

사진은 브라우저에서 처리되고 외부 서버로 업로드되지 않습니다. 출력은 Chrome/Edge 등 MediaRecorder를 지원하는 브라우저의 WebM 동영상입니다. 길이 선택은 10초, 25초, 40초이며 화면 비율과 720p/1080p 품질을 제공합니다.

## 제작 범위

영상은 업로드한 사진을 순서대로 연결하고 천천히 확대 이동하며 차량명·가격·문구와 엔드 카드를 얹어 브라우저가 실제 인코딩합니다. 원본 서비스의 AI 이미지/영상 생성 엔진, 계정·결제·크레딧, 음성·음악, 사진 게시물 생성 기능은 이 앱에 연결되어 있지 않습니다. 따라서 원본과 같은 생성형 AI 결과물을 만든다고 표시하지 않습니다.

## 개발

```sh
npm ci
npm run dev
npm run build
```

GitHub Pages 배포는 `.github/workflows/deploy.yml`이 `main` 브랜치 변경 시 자동 실행합니다.
