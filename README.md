# StudioOS by iamjapinder

중고차 사진으로 세로 숏폼 영상과 SNS용 사진 게시물을 만드는 한국어 웹앱입니다. 현재 화면은 사용자가 지정한 `iamjapinder.com/create`를 참고해 구현했습니다.

## 사용 방법

1. 사진 또는 영상 모드를 고르고 차량 사진을 추가합니다. 파일을 끌어다 놓을 수도 있습니다.
2. 차량명, 가격, 소개 문구를 입력하고 스타일·길이·비율·화질을 설정합니다.
3. 영상 모드에서는 브라우저에서 사진 슬라이드 영상을 만들고, 원하는 경우 본인 음성이나 음악 파일을 추가합니다.
4. 사진 모드에서는 스타일과 비율을 정해 PNG 게시물 이미지를 만듭니다.
5. 결과를 미리 보고 WebM 영상 또는 PNG 이미지를 다운로드합니다.

## 현재 연결된 기능

- 사진 업로드, 정렬 및 삭제 (최대 12장)
- 사진의 이동·확대와 스타일별 색감 처리를 포함한 9:16/4:5/1:1/4:3/16:9 영상 생성
- 10초/25초/40초, 720p/1080p 설정, 차량 정보와 엔드 카드
- MP3, WAV, M4A 등 사용자가 선택한 오디오 파일을 브라우저에서 영상에 믹싱
- 차량명·가격·소개 문구를 넣는 SNS 사진 게시물 PNG 생성

사진과 오디오 파일은 브라우저에서 처리되며 앱 서버에 업로드하지 않습니다. 영상 출력은 MediaRecorder를 지원하는 Chrome/Edge의 WebM 형식입니다.

## 원본 AI 연동 범위

원본 서비스의 생성형 영상·사진 엔진을 호출하는 공개 개발자 API 문서나 API 자격 정보는 현재 제공되지 않았습니다. 따라서 원본의 비공개 API를 추측해 호출하지 않습니다. 현재 결과는 실제 브라우저 렌더링/사진 구성으로 생성되며, 원본 생성형 AI 결과라고 표시하지 않습니다. 사용자가 선택한 음성·음악 파일을 믹싱할 수 있지만 음성 합성·음악 생성 API는 연결되지 않았습니다.

원본 AI 엔진을 실제로 연결하려면 소유자의 공식 API 문서와 서버용 API 자격 정보, 해당 서비스를 호출할 백엔드 호스팅이 필요합니다. 비밀 키를 브라우저 코드나 공개 GitHub 저장소에 넣지 마세요.
